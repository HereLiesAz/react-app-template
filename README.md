# React App Template

Minimal React + TypeScript + Vite starter.

## Stack

- React 19.3
- TypeScript 7
- Vite 8.3
- strict TypeScript
- no application framework or styling framework imposed

Install with `npm install`, develop with `npm run dev`, and build with `npm run build`.

## Workflows

Select central automation in `.github/workflow-request.yml`. New workflow implementations must be generalized and submitted to `HereLiesAz/workflows`.
